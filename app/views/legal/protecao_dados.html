Proteção de Dados Pessoais — Sistema SIME

O Sistema Integrado de Membros e Estatística (SIME) compromete-se a respeitar princípios fundamentais de proteção de dados pessoais de todos os membros cadastrados, utilizadores do sistema, Pastores e dados organizacionais que incidem sobre uma pessoa fisica ou juridica.

1. Princípios Gerais

Os dados pessoais devem ser:

  • Utilizados apenas para finalidades legítimas;
  • Mantidos atualizados;
  • Protegidos contra acesso não autorizado.
O sistema não possui finalidade comercial pública nem recolhe dados para publicidade.

2. Responsabilidade da Instituição

    A Igreja Manancial da Esperança assume responsabilidade direta pela correta utilização dos dados inseridos no sistema.

    Cabe à instituição:

  • Definir operadores autorizados;
  • Garantir confidencialidade;
  • Evitar divulgação indevida.

3. Direitos dos Titulares dos Dados

Os membros cujos dados estejam registados possuem direito a:

  • Solicitar correção de informações;
  • Atualizar dados pessoais;
  • Solicitar eliminação quando aplicável.

4. Segurança Técnica

O sistema permite medidas como:

  • Controlo por senha;
  • Registo de atividades (logs), quando ativados.
    • Recomenda-se:
  • Backup regular;
  • Uso em computadores protegidos.

5. Transferência de Dados

Os dados não devem ser transferidos para terceiros sem autorização institucional formal.

6. Conservação dos Dados

Os dados serão mantidos enquanto necessários à finalidade administrativa e histórica da organização.
